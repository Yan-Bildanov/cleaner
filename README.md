# Cleaner

Простая и осторожная замена CCleaner и IObit Uninstaller Pro для Windows 10/11 — бесплатно и без рекламы.
Чистит кэши и временные файлы, удаляет программы вместе с их хвостами, находит подозрительные расширения
браузеров, проверяет «здоровье» ноутбука и умеет чистить по расписанию. Тёмный интерфейс в стиле Windows 11,
один `.exe` без зависимостей.

Главный принцип — **ничего не удалять сразу**. Всё, что очищено или удалено, 7 дней лежит в карантине
и возвращается на место одной кнопкой: файлы, папки, ключи реестра, службы, задачи Планировщика, автозагрузка.

## Возможности

**Очистка**
- Анализ → список с галочками и размерами → очистка. Без подтверждения ничего не удаляется.
- Временные файлы Windows, кэш эскизов, отчёты об ошибках, загрузки Центра обновления.
- Кэш браузеров Chrome и Edge (только кэш — без cookies и истории, все профили).
- Кэш приложений: Telegram, VS Code, Claude; кэши разработчика: pip, npm, NuGet.
- Свои пункты очистки — в личном файле `%USERPROFILE%\.cleaner\rules.local.json` (формат — в `src/Cleaner.Core/Rules/LocalRules.cs`).
- **Карантин на 7 дней** с кнопками «Вернуть» и «Удалить навсегда».
- Корзина — отдельным подтверждением (это единственное безвозвратное действие).
- Файлы, которые сейчас открыты другой программой, не трогаются.
- Точка восстановления Windows перед очисткой (по желанию).

**Программы** — замена IObit Uninstaller Pro
- Список всех установленных программ и приложений Microsoft Store: значок, издатель, версия, дата, размер; поиск и сортировка.
- Удаление собственным деинсталлятором программы, а затем **поиск хвостов**: папки, ярлыки, ключи реестра,
  службы и задачи Планировщика. Совпадения ищутся только по точному имени; папки других программ и системные
  места (Windows, Microsoft, Защитник) не предлагаются никогда. Всё найденное — в карантин.
- **Пакетное удаление** нескольких программ подряд и тихий режим без вопросов (MSI, Inno Setup, NSIS).
- **Принудительное удаление**, если деинсталлятор пропал или не работает: процессы программы закрываются,
  её файлы, службы, задачи и запись в списке установленных убираются — тоже через карантин.
- **Монитор установок**: снимок системы до и после установки (меньше секунды, без драйверов). При удалении
  такой программы всё, что она поставила, находится точно по записи — включая автозагрузку и сопоставления файлов.
- Защита от случайностей: Microsoft Store, установщик приложений (winget) и другие важные пакеты удалить нельзя.

**Расширения браузеров**
- Все расширения Chrome, Edge, Brave, Vivaldi и Яндекс Браузера по всем профилям: откуда взялось, включено ли, права.
- Предупреждения по делу: подменяет поисковую систему, домашнюю страницу или новую вкладку; поставлено программой без ведома пользователя.
- Расширения, которые подсовывают программы через реестр, удаляются окончательно — браузер убирает их сам
  и они не возвращаются. Остальные — одной кнопкой открывается их страница в нужном профиле браузера.

**Система**
- Проверка здоровья: диск и износ SSD, батарея, температура, обновления Windows и время без перезагрузки,
  антивирус и брандмауэр, автозагрузка (включая службы удалённого доступа вроде AnyDesk).
- Информация о железе: модель, процессор, память по планкам, видеокарты и драйверы, накопители, BIOS.

**Расписание**
- Автоочистка через Планировщик заданий Windows: раз в неделю, каждый день или «когда мусора больше 1 ГБ».
- Если ноутбук был выключен в назначенное время — очистка запустится при следующем включении.
- Строже ручной: корзину и системные пункты не трогает, открытые приложения пропускает.
- Уведомление с результатом, ярлык «Быстрая очистка» на рабочем столе.

Чего здесь **нет** намеренно: общей «чистки реестра» (удаляются только ключи удалённой программы — и то с копией),
«ускорителей», обновления программ и драйверов.

## Установка

Нужны Windows 10 версии 2004 или новее и [.NET 10 SDK](https://dotnet.microsoft.com/download) (только для сборки).

```
git clone <адрес репозитория>
cd cleaner
tools\install.cmd
```

Скрипт соберёт один `Cleaner.exe` (~80 МБ, .NET внутри), положит его в `%USERPROFILE%\.cleaner\app`
и создаст ярлыки на рабочем столе и в меню «Пуск». Повторный запуск — обновление.

Некоторые действия (системные временные файлы, точка восстановления, износ SSD, удаление хвостов в Program Files
и в общем реестре) требуют прав администратора — Windows спросит разрешение только для них.

## Где программа хранит данные

`%USERPROFILE%\.cleaner` (скрытая папка): карантин, записи монитора установок (`traces`), настройки,
журналы (`logs\errors.log`, `logs\auto.log`).
