# Cleaner

Простая и осторожная замена CCleaner для Windows 10/11: чистит кэши и временные файлы, проверяет «здоровье»
ноутбука и умеет делать это по расписанию. Тёмный интерфейс в стиле Windows 11, один `.exe` без зависимостей.

Главный принцип — **ничего не удалять сразу**. Всё, что очищено, 7 дней лежит в карантине и возвращается
на место одной кнопкой.

## Возможности

**Очистка**
- Анализ → список с галочками и размерами → очистка. Без подтверждения ничего не удаляется.
- Временные файлы Windows, кэш эскизов, отчёты об ошибках, загрузки Центра обновления.
- Кэш браузеров Chrome и Edge (только кэш — без cookies и истории, все профили).
- Кэш приложений: Telegram, VS Code, Claude; кэши разработчика: pip, npm, NuGet.
- Свои пункты очистки — в личном файле `%USERPROFILE%\.cleaner\rules.local.json` (формат — в `src/Cleaner.Core/Rules/LocalRules.cs`).
- **Карантин на 7 дней** с кнопками «Вернуть» и «Удалить навсегда».
- Корзина — отдельным подтверждением (это единственное безвозвратное действие).
- Файлы, которые сейчас открыты другой программой, не трогаются.
- Точка восстановления Windows перед очисткой (по желанию).

**Система**
- Проверка здоровья: диск и износ SSD, батарея, температура, обновления Windows и время без перезагрузки,
  антивирус и брандмауэр, автозагрузка (включая службы удалённого доступа вроде AnyDesk).
- Информация о железе: модель, процессор, память по планкам, видеокарты и драйверы, накопители, BIOS.

**Расписание**
- Автоочистка через Планировщик заданий Windows: раз в неделю, каждый день или «когда мусора больше 1 ГБ».
- Если ноутбук был выключен в назначенное время — очистка запустится при следующем включении.
- Строже ручной: корзину и системные пункты не трогает, открытые приложения пропускает.
- Уведомление с результатом, ярлык «Быстрая очистка» на рабочем столе.

Чего здесь **нет** намеренно: чистки реестра (бесполезна и рискованна), «ускорителей», обновления драйверов.

## Установка

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download) (только для сборки).

```
git clone <адрес репозитория>
cd cleaner
tools\install.cmd
```

Скрипт соберёт один `Cleaner.exe` (~75 МБ, .NET внутри), положит его в `%USERPROFILE%\.cleaner\app`
и создаст ярлыки на рабочем столе и в меню «Пуск». Повторный запуск — обновление.

Некоторые пункты (системные временные файлы, точка восстановления, износ SSD) требуют прав администратора —
для них в программе есть кнопка «Права администратора».

## Где программа хранит данные

`%USERPROFILE%\.cleaner` (скрытая папка): карантин, настройки, журналы (`logs\errors.log`, `logs\auto.log`).
